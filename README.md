# Arbora

Gestão do pomar e do sítio: calendário das culturas, acontecimentos, colheitas e relatórios. MVP em React + Vite + TypeScript + Tailwind + Supabase.

**Documentação completa em [docs/README.md](docs/README.md)**: instalação, Supabase, Vercel, banco de dados e segurança.

```bash
cp .env.example .env.local   # preencha URL e chave PÚBLICA do Supabase
npm install
npm run dev
```

> MVP **sem login**: quem tiver o endereço acessa os dados. Use só para demonstração. Ver [docs/SEGURANCA.md](docs/SEGURANCA.md).
